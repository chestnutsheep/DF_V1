## 各周期机构指标（来自 Obsidian 知识库）

### Kondratiev ✅ 已达114年
**核心指标**:
- 大宗商品实际价格指数 (经通胀调整) → PPIACO (1913~, 113yr) + CPIAUCSL (1947~)
- 全球/主要经济体长期实际GDP → WB World GDP (1961~) + GNPCA (1929~)
- 利率长期变动趋势 → GS10 (1953~)
- 工业产出 → INDPRO (1919~, 107yr)

**当前状态**: 1913~2026 (114yr, 6指标) ✅ 接近目标

### Kitchin（基钦周期）
**机构指标**:
- 核心: 工业企业产成品存货同比 + 工业企业营业收入同比
- 辅助: PMI, PPI, M1
- 方法: 傅立叶变换+高斯滤波, 42个月周期

**当前**: 中国NBS数据 2001~2026 (25yr)
**延展方案**:
- 主判定: 维持NBS真实数据 2001~ (最近3轮完整周期)
- 长参照: INDPRO (FRED, 1919~, 108yr) 做长波基准
- 辅助: 中国GDP估计 (Maddison项目, 1840~)

### Juglar（朱格拉周期）
**机构指标**:
- 核心: 设备工器具购置投资 + GDP同比
- 领先: PMI, M2/社融, 企业中长期贷款
- 同步: 产能利用率, 工业机器人/机床产量
- 方法: CF带通滤波 6-12年, 小波变换

**当前**: NBS固投/设备数据 2000~2026 (26yr)
**延展方案**:
- 主判定: 固定资本形成总额 (WB, 1960~, 65yr)
- 长参照: GNPCA (FRED, 1929~, 97yr)
- 扩展: 全球资本形成总额序列 (WB, 1960~)

### Kuznets（库兹涅茨周期）
**机构指标**:
- 核心: 房地产投资 + 新开工面积 + 销售面积
- 长期: 人口结构 + 城镇化率 + 人均居住面积
- 辅助: 土地购置, 住房贷款利率
- 方法: 频谱分析 + HP滤波, 15-25年

**当前**: NBS房价/销售 2011~2026 (15yr, 最短)
**延展方案**:
- 长序列: 城镇化率 (WB, 1960~, 65yr)
- 长参照: HOUST (FRED 新屋开工, 1959~, 67yr)
- 人口: 劳动年龄人口 (WB, 1960~)
- NBS核心: 保留房地产投资/新开工 (2000~)
